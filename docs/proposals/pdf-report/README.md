# P2-04B PDF资料报告方案

2026-10-25。用户已明确批准「批准，按此接入现有页面」；不包含ZIP、发布或全项目历史重建。

## 入口、范围与操作

Owner与有效Guest均可用，归档可导出。在现有资料筛选栏旁增加「PDF资料报告」，展开后在已有图片条目旁勾选，最多8张，按选择顺序合并。选择仍使用现有图库、分页与类型／排序；切换筛选时清空选择并提示，不另建报告中心。单张图片的原导出表单也加入PDF选项，原PNG／JPG继续可用。

```text
类型 [图片]   排序 [最新上传]   [PDF资料报告]
已选 2 / 8 张 · 当前已保存状态  [生成PDF] [取消选择]
[✓] 正面.jpg       [✓] 背面.jpg       [ ] 侧面.jpg
生成中：照片2/2… [取消] / 失败原因 [重新生成]
```

只导出所选标准图、已保存七类几何、工程师人工字段／单位、客户数值及回复方式／状态，以及这些标注关联的已有回复／补测／历史确认记录。证据照片保留有权文件名和ID引用，不默认嵌入证据附件或CAD/PDF原文件。旧位置记录注明其固定修订，不把历史数值套到当前几何；缺失值不补零，绿色不表示尺寸齐全。

## 报告布局

推荐A4纵向，每张照片从新页开始，随后接其详细说明，页眉标明照片序号与文件名，页脚连续页码。

```text
项目名 · PDF资料报告                         页1
照片1 / 2 · 正面.jpg · 当前已保存状态 / 固定时间
┌ 完整标准图 + 七类标注 / 定位编号 / 适用数值 ┐
└ 保留宽高比、不裁剪、不带编辑器控件         ┘
图片尺寸 / 来源hash与文件ID

标注1 · 名称 · 修订
工程师人工值；客户数值／仅照片／无法测量／待补测
来源及相关回复／补测记录，长段落续页
──────────────────────────────────────────
已补充不等于尺寸齐全或技术验收 · 非正式CAD工程图
```

长块尽量整块换页；超过一页的长备注按行续页并重复照片上下文和「续」，不裁断照片、字行或丢尾部内容。不新增漂亮封面、营销装饰或AI摘要。原位表单复用现有按钮／select／状态、分隔线；小屏换行、勾选区至少40px，键盘可达，生成期间禁止改选。

采用浏览器Canvas将每页以约192dpi绘制，再以高质量JPEG嵌入标准PDF；中文使用设备现有字体，不需字体网络下载或新运行依赖。**文字可阅读、缩放和打印，但该轻量版不提供文字选择／搜索、可编辑表格或正式CAD矢量工程图。** 相比引入字体包与完整排版引擎，优先复用现有绘制、控制体积与环境依赖；若必须搜索文字则另议该实现取舍。

## 一致性、上限与状态

一次请求在同一项目读锁内固定所有选中照片的hash、标注ID／修订及相关来源引用；生成期间不混入新保存内容。逐张读取受控标准图并校验hash，保存前再次批量核权全部照片；撤销／退出／切换项目／取消时放弃结果。下载仅交给浏览器，已保存副本无法撤回。

最多8张照片／60页／40MiB PDF、800个有效标注、2000条相关历史记录、120000字符报告正文；快照JSON最多2MiB。每张标准图沿用40MP／80MiB，逐张解码、逐页编码与释放，不并行堆照片；应用缓冲估算上限512MiB（浏览器原生分配和GC额外），总计180秒。组合超限明确提示减少所选照片，不静默截断、后台永续生成、自动分包或新增服务。

空项目／非图片无勾选对象，明确提示选图片；生成按钮在未选时禁用。加载、重复点击、断网、解码／编码失败、超限、权限不足、撤销分别原位反馈，可取消并重试重新固定快照。没有新增数据写入、migration、常驻Worker、外部字体或收费服务；仍不启动浏览器／E2E或部署。

## 自检与待决策

无渐变；原冷灰／白／石墨／蓝操作，非暖黄主色；无AI装饰；只在已有资料条目添加选择与一行操作，不套多层卡片。报告同样用文字、留白和分隔线组织。

已批准：上述最多8张的当前已保存范围、相关历史引用、A4布局和轻量不可搜索PDF取舍。微小排版按现有UI自主实现，样本分页／中文用离线渲染定向核对，真实阅读／手机保存最后交人工。
