## 修正与用户收益

| 代码中发现的问题 | 本次处理 | 预期体验 |
| --- | --- | --- |
| 已选标注的 draggable 只检查可编辑与空格状态，没有区分当前工具 | 仅选择工具允许拖动对象及显示控制点；平移工具保持选中对象但不编辑几何 | 在已选标注上拖动平移时，不误移标注；绘制新形状时不拖走旧形状 |
| 整对象拖动没有控制点已有的取消／原对象核对；双指打断停止拖动时可能触发 dragend | 保存拖动起始对象，取消时先清空事务再停止节点；释放时核对当前对象、权限与图片，复用同一提交判定 | Esc、双指、失焦、触摸取消或图片切换中断手势时，不把临时移动误记为修改；实际几何／属性更新时拒绝覆盖 |
| 对象整体移动时，控制点仍留在拖动前的位置 | 整对象移动期间暂隐控制点，释放后恢复 | 不出现轮廓已移动、控制点还停在旧位置的误导 |
| 触摸取消只清理部分状态；双点复位没有像鼠标一样保护三点工具 | 集中清理绘制、平移、缩放、控制点和三点状态；双点／双击复位仅在选择／平移模式且无抑制标记时执行；右键不落三点 | 角度／圆弧绘制不因连续双点意外复位；取消后不会带着旧点继续画 |
| 缩放或容器尺寸变化可以发生在拖动途中 | 取消当前指针拖动再改变视图；普通缩放保留已经点击的角度／圆弧点，双指切换沿用取消当前绘制的规则 | 避免旧坐标系下的拖动被当作新位置；三点绘制可放大后继续取点 |
| 点击工具栏后焦点停留在按钮；保存快捷键只在画布内生效 | 工具／撤销／缩放操作后回到画布；属性输入内也能 Ctrl+S／⌘S 保存标注；保留输入控件自身的撤销与删除，跳过输入法组合事件 | 选工具后可直接用 Esc、空格和方向键；填写属性后无需再点一次画布才能快捷保存 |
| React 渲染前到达的读取结果可能看不到最新的本地 dirty 状态；无效位移也会进入撤销栈 | 本地修改、撤销／重做、开始保存时立即保护草稿；无内容变化不记历史；重新读取清空旧编辑分组，撤销／重做清理失效选中 ID | 减少后台更新覆盖刚输入内容的时序风险；移到边界后不需要反复撤销无效动作 |

拖动提交保留最新只读协作摘要，不用旧的待补／已补状态覆盖新的客户回复；几何移动不会修改人工数值。固定修订、历史、正常保存、Guest 只读和红／黄／绿语义沿用现有实现。工具栏、属性聚合、资料分组卡片及两个主 Section 保持；只增加光标提示和保存快捷键提示，无 CSS 布局改动。

## 人工验证（约 5 分钟，待执行）

在本机使用现有合法配置运行 `npm run dev`；工程师与客户沿用正常登录／分享入口。不要用旧远程 Preview 代验。

1. **平移与取消**：选中线段／椭圆，切到平移工具，在标注上拖动，应只移动视图。切回选择，拖动对象／控制点时按 Esc，再松手，应恢复拖动前位置；正常释放一次，再撤销一次应回到原位。
2. **三点与缩放**：放大图片后快速点角度／圆弧的前两点，视图不应复位；用滚轮或工具栏放大后继续第三点。手机试双点与双指缩放：双指结束不额外落点，取消后无旧三点残留。
3. **键盘与属性**：点击线段工具后直接按 Esc；点击选择／缩放后用空格拖动、方向键微调。修改人工尺寸后在输入框内 Ctrl+S／⌘S，应保存标注而非打开网页保存；输入框中的删除／撤销仍按文本处理。
4. **切换与协作**：修改标注属性，切到本图其他标注后返回，草稿仍在；待办填写未提交时尝试切换并取消提示，原输入仍在。同图／跨图查看当前标注、固定位置以及 Guest 只读位置是否一致。
5. **一轮回复**：选一个已有待补项，提交数值／照片／无法测量中的一种，查看已补充状态与旧记录；条件允许再走一次补测。只有照片或无法测量时，绿色不代表尺寸齐全。完整三种回复与其他 P0 待验用例继续沿用原人工清单。
