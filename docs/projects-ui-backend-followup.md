## 已实现的前端范围

- 桌面左侧常驻分类栏，品牌置顶，「全部」在文件夹之前，右侧保留项目行列表；手机通过按钮打开左侧抽屉。
- 文件夹列表单独滚动；退出登录固定在侧栏/抽屉底部，与文件夹数量无关。
- 右下角胶囊「新增」打开居中原生 dialog，暗色遮罩；保留名称、说明及已有项目创建接口、CSRF 与幂等键。错误保留输入，提交期间禁止关闭和重复提交。
- 文件夹新建、重复名称校验、分类切换、新建项目选择文件夹在页面内存中工作。项目卡片右侧的归类控件已按第三轮要求删除。为避免跨账号残留，不使用无账号隔离的 localStorage/sessionStorage；页面明确提示刷新后重置。
- 新建项目成功后关闭弹窗，在选定分类的列表中显示真实接口返回的项目；点击项目进入工作台。这样在后端文件夹尚未接入时，页面内临时分类不会因创建后的自动跳转立即丢失。项目本体仍由现有后端持久保存。
- 分类只对已加载项目生效，分页存在时标注「已加载」，可继续加载更多；不将当前页计数当成全库总数。

## 后续后端设计草案（未实施，须另行批准）

建议采用单层文件夹，每个项目最多归属一个文件夹，不实现嵌套树。

| 对象 | 建议字段/能力 | 约束 |
| --- | --- | --- |
| project_folders | id、owner_id、name、description、color、created_at、updated_at；排序需要时另加 sort_order | owner 归属强制验证；去空白、名称长度和同账号重名规则前后端一致；description 可选、最多 500 字符；color 只允许 blue/cyan/green/purple/rose/coral/slate 七种标识，不接受任意 CSS |
| projects | 可空 folder_id | 空值代表暂未分类；「全部」是查询视图，不是数据库文件夹；folder 与 project 必须同一 owner |
| 现有项目读取/创建接口 | 返回/接受 folder_id；归类更新接口 | 保留现有认证、CSRF、幂等及 revision 规则，不能相信客户端 owner_id |
| 文件夹接口 | 当前账号列表、新建、项目归类 | RLS 默认拒绝；其他账号及 Guest 无读写权限 |
| 列表查询 | 按文件夹分页、准确数量 | 不在前端加载一页后冒充全部；现有分页游标需与分类绑定 |

改名/删除文件夹的交互与删除后归类规则尚未批准，不在本轮扩展；后续设计必须保证删除分类不会删除项目及其资料。后端接入完成后移除临时内存和提示，保留当前页面交互。

## 第二轮：配色、圆角、动效与手机弹窗

2026-10-18，用户批准动效预览后追加约束：禁止任何半透明背景；不擅自打开浏览器验证。此约束适用于本轮及后续本页面工作，除非用户另行明确授权。本轮不启动浏览器、Playwright 或 E2E，不重新使用第一轮浏览器结果宣称本轮视觉已通过。

已完成：

- 两个弹窗显式按可视区域中心定位，覆盖 Tailwind preflight 对 dialog 的默认 margin 重置。手机宽度最多为视口减 24px，桌面宽度最多 480px；手机七色选择分为四列，表单过高时内部滚动。监听 visualViewport 高度和偏移，为软键盘/可视区域变化提供尺寸约束；实际设备效果仍待人工审查。
- 文件夹说明（可选，500 字符）与七个固定低饱和度颜色；颜色用于文件夹条目。名称、说明和颜色均只存当前页面内存，刷新后重置，后端未改。
- 切换分类时，从被点击条目在视口内的中心向全页扩散纯色；手机先完成抽屉退场，再按捕获的点击位置扩散。只使用一个视口大小的实色层，动画为圆形 clip-path；结束后写入背景并释放动画及 will-change。避免创建直径数倍于视口的大型圆形图层，不在 JavaScript 中逐帧计算。
- 每个项目放入 24px 圆角容器，背景与当前分类保持同色相、不同深浅；弹窗 32px（手机 30px），输入、按钮和文件夹条目统一增大圆角。
- 弹窗/抽屉保留原生 dialog 的焦点约束与恢复；进场、退场、分类内容、新项目/文件夹、错误提示和控件状态加入短过渡。退场完成后才真正 close；提交中的项目弹窗禁止取消。减少动态效果偏好下缩短/省略运动。
- 所有显式背景使用不透明 RGB 实色。没有透明背景、Alpha 色、透明度渐隐、模糊或半透明阴影；禁用控件覆盖既有 opacity: .6 为 1。弹窗背后为完全不透明的暗色实底，暗化通过实色之间的插值完成，因此不会透出下面页面。
