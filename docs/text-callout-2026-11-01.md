# 箭头文字工具实施记录

2026-11-01（Asia/Taipei）。用户明确修正为“起点是箭尾，终点是箭头尖”，并批准开始实现。状态：本地实现与验证完成；未提交、推送、生产部署或应用云端迁移。先前首页登录入口修改仍保留，本批未覆盖。

## 行为

- 工具栏“文字”改为“箭头文字”，移除新增“点位”入口。按下位置为箭尾／文字端，拖动结束位置为箭头尖。点击而不拖动不生成零长度箭头。
- 正文直接显示在照片上，箭头和正文固定红色 `#dc2626`，不随协作状态变色。两个手柄分别调整文字端和目标端；整体拖动、键盘移动、撤销／重做、连续绘制、保存冲突沿用既有机制。
- 属性只保留一个“说明文字”输入框，沿用 500 字上限。旧名称和备注保留只读查看。列表标题从正文首行生成，文字标注不显示补尺寸提示，不自动产生数值待办。
- 编辑器、Guest 共用画布、图库 SVG 及 PNG／JPG／PDF 共用导出绘制均接入同一箭头和文字布局。支持换行、靠边排布、长文本缩小至图内；长文本在小照片上可能变小，完整正文仍保存在标注中。
- 旧点位类型及其读取、编辑、补充和历史仍受支持。旧文字保留原 `at` 目标位置，缺少文字端坐标时按确定规则显示默认引线；不批量重写旧记录。用户首次调整旧文字位置时才将两端坐标写入新的正常修订。

## 数据与发布顺序

沿用 `type: text` 和原 `at` 目标坐标，仅增加可选 `labelAt` 箭尾坐标。前后端共用的严格 Zod 校验、拖动边界和数据库校验同步适配。无需新表、新 API、权限放宽、依赖或历史数据转换，原 schemaVersion 和不可变修订规则保持。

新增迁移：`supabase/migrations/20261101112009_text_arrow_callout.sql`。由 Supabase CLI `migration new` 创建；只替换现有 `pm.valid_annotation_geometry_v1(jsonb,integer,integer)`，允许文字携带受严格校验的可选坐标，继续拒绝未知字段、越界／非数值／零长度坐标。主几何校验函数继续委托原路径；非文字规则不变，security invoker、执行权限保持。

生产发布时必须先应用这条向后兼容的校验迁移，再发布应用。当前生产库未应用此迁移，因此本批不能直接描述为线上可用。旧应用代码不应作为新箭头编辑能力的回退保证；如后续回退应用，保留已兼容的数据库校验，不能删掉历史箭尾信息。任何正式应用迁移前，遵循原人工备份流程及具体发布范围。本轮没有云端写入或执行备份。
