项目列表继续保留当前搜索、文件夹、项目条目和新增入口。在列表标题下增加一行状态选择，项目条目增加轻量归档／恢复动作：

```text

原有搜索与文件夹继续组合使用

项目名称             归档 / 恢复

```

默认查看进行中项目，归档后从该结果移出；切到已归档可恢复。项目详情的原「编辑说明与分享」内也提供归档／恢复，归档前提示只读影响及未完成上传影响，不新增业务页面或大弹窗。

资料区仍使用原图库／文件条目，仅在图库上方聚合两项选择：

```text

原待办入口
类型 [全部资料 ▾]    排序 [最新上传 ▾]
原有图库、文件条目、加载更多
```

类型：全部、图片、PDF、CAD、ZIP。排序：最新上传、最早上传、文件名。双端同样提供；项目搜索／状态／文件夹和资料类型／排序全部在服务端筛选后分页，不只筛已加载内容。切换条件返回第一页、取消过时读取；显示当前条件的空态，切换前保护未保存输入。不更改标注编号、待办范围或交付附件集合。

## 归档权限和分享策略

推荐只采用一个明确状态：

| 能力 | 进行中 | 已归档 |
|---|---|---|
| Owner／有效Guest查看有权资料、历史、已发布交付并下载 | 沿用 | 保留 |
| 上传、保存标注、回复／补测、交付草稿／发布、客户留言／接收 | 沿用 | 暂停，页面只读，服务端拒绝写入 |
| Owner编辑项目说明、生成／重发分享 | 沿用 | 恢复后再操作 |
| Owner恢复项目、撤销已有分享 | 可归档／撤销 | 可恢复／撤销 |

归档不删除、移动或清理文件与历史，原文件夹归属保留，存储仍计入配额。已存在且未过期／撤销的客户链接仍可只读访问；恢复不复活已撤销或过期链接，也不自动生成新链接。Guest无归档／恢复权限。

归档后新打开客户端仍可建立只读分享会话；认证、读取、下载及必要清理不因只读而失效。进行中的上传可能暂停或无法完成，需要恢复后继续／重新选择，不承诺归档期间后台持续完成。其他页面收到归档事件后显示只读提示并停止新的写入；已有文字输入尽量原位保留供恢复后继续，不静默覆盖。
