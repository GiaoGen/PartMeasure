## 文件夹颜色与后端边界

分类关系仍只存在于列表当前页面内存。项目链接根据“该项目 → 文件夹”查找颜色，附带七种固定标识之一的 theme 查询参数；从“全部”进入也读取项目自身归属。

参数只表示外观，不携带文件夹名称、说明、账号或私有内容，不参与权限或数据库查询。客户端只接受七个自有颜色键，非法值回落默认主题；Guest 忽略提示，保持默认主题。带参数的工程师链接刷新可恢复颜色；服务端首屏与加载占位为默认主题，客户端恢复后应用目标颜色。

直接打开不带提示的旧链接、跨设备或刷新列表后，前端无法重新推断归属，使用默认色。未引入无账号隔离的持久存储。文件夹与项目关系持久化、详情返回颜色仍待后端接入，见 projects-ui-backend-followup.md；本轮无需新增独立数据库字段，不能把外观参数视为持久化完成。
