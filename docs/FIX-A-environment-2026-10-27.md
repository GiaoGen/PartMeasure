## 实质交付

新增`npm run diagnose:connection`及`connection-cli.ts` / `connection-model.ts`，复用应用实际runtime事务和事件连接、原有账号及样本，默认离线。四种模式：

| 命令后缀 | 实际动作 |
|---|---|
| 无 | 检查隔离目标/受限角色/端口及源码指纹，不联网 |
| `-- --probe` | Auth settings严格HTTPS、实际runtime严格TLS/SELECT、session连接LISTEN后关闭；不发事件、不写业务资料 |
| `-- --api` | 正常Owner A/B密码登录、当前会话、旧合成项目/文件读取、Owner原件hash及另一Owner项目/文件404 |
| `-- --api --apply` | **每次执行须有相应云写入授权**。只新建一个合成项目及一个125字节私有STEP附件，经正常API预留/签名/上传/请求内完成/下载hash；不能指定既有项目为写目标，不自动清理 |

连接错误在首个失败阶段停止；请求/事务有时限，无自动网络重试或降级。只输出固定阶段、耗时、有限错误分类/传输码和必要hash，不输出密码、Cookie、能力地址、SQL、私有名称或供应商错误原文。记录逐文件SHA-256与运行期间源码不变断言，不引用旧buildId来证明当前代码。

没有依据修改生产连接实现或重建登录/上传。修正的是可复用验证入口和执行办法；手册已补同源码/同环境复跑、业务读操作的限流副作用、正常Auth会话及故障分层。
