# P1-04：CV 正式接入

日期：2026-10-25。用户明确授权 P1-04，要求沿用现有 UI／排版，主要时间用于实现，必要定向检查后把拖拽／手机体验交人工。开工估时2–3小时。范围按[P1-03收尾建议](P1-03-assessment-2026-10-25.md)：轻量 OpenCV.js 辅助，不追求复杂照片普遍识别，不增加 EdgeDrawing 浏览器编译或 AI。

## 用户可见行为

现有画布工具区增加“边缘贴合”开关（默认关闭）和“识别圆／椭圆”按钮。白底、冷灰、原主题强调色、4px圆角、44px触摸目标沿用现有控件；手机宽度下辅助控件换到同一工具区的下一行。属性区保持原有字段聚合，不另嵌套照片或新增保存流程。

- 开启后，新画的线段／角度／圆／椭圆在完成绘制时尝试贴合。原画先立即成为普通未保存草稿，计算不锁住手动编辑；无可靠结果或失败保留原画。点、文字、圆弧继续手动。
- 贴合只影响仍被选中的原新建草稿，作为独立撤销步骤；一次撤销恢复粗画，再次撤销才撤销创建。手调、属性修改、选择其他标注、撤销／重做、保存、图片切换或版本变化都会使旧结果失效。不会因修改旧标注而重新触发贴合。
- 主动识别最多12个圆／椭圆候选；虚线和“候选”标签区别于正式标注，按钮悬停／键盘聚焦可突出对应轮廓。选用后作为可编辑草稿，随后使用现有属性与保存。未采用的候选不进入标注、待办或历史；可清除候选。
- 加载／计算时有状态与“取消辅助”。关闭边缘贴合、取消、按Esc清除或继续手动操作均不会删除原草稿。候选只是轮廓，不表达物理孔或已确认尺寸；数值仍由人提供。

## 运行与资源边界

- 正式运行依赖只增加已实验的 `@techstark/opencv-js@4.12.0-release.1`（Apache-2.0）。`esbuild@0.28.2`（MIT）作为精确固定的构建依赖，已有传递版本复用。npm lock固定；不使用远端CDN、AI服务或新检测后端。
- P1-03 算法原样提升到 `src/lib/cv/core.ts`，仅调整类型／几何导入路径；历史独立实验保持冻结，避免覆盖原证据。本轮未围绕压力照片继续调参。
- OpenCV 发行物10,872,779字节，SHA256 `bd0c3e6448043de04f6a64a12cb7b759f78c3ab8f7c35c9f2e0f71c88bb17103`。构建时校验并复制到固定版本／哈希的静态路径，附上游LICENSE；浏览器可长期缓存该公开代码。照片与候选结果不写入此目录，也不进入新增持久缓存。
- `npm run dev`／`npm run build` 的前置步骤自动生成静态资产；单独执行 `npm run cv:build` 亦可重建。`public/cv/` 是生成目录，不提交二进制，正常部署构建会生成。Worker脚本不缓存，避免代码更新后继续使用旧匹配逻辑。
- 页面只在开启后完成绘制或主动检测时加载小客户端模块、创建同源浏览器Worker；OpenCV在Worker中加载，不进入页面主包或在Guest端预加载。计算线程在取消／错误／图片切换／卸载时终止，成功后空闲45秒也终止。
- 单图最长边1024、最多1,048,576像素、最多2000轮廓、一次1个局部草稿、最多12个可见候选。只从已有核权并解码的标准图创建有界像素副本，不另请求照片或上传服务。等比缩放加不足1px边界填充，坐标映射保留物理像素圆与椭圆垂直轴；映射回标准图后再次校验。
- 初始化20秒、计算8秒上限；取消直接终止线程，不等待同步CV循环响应。初始化不等待 Emscripten 自解析 thenable，避免之前实验遇到的无限等待。
- 文档CSP仅增加同源 `worker-src`。`unsafe-eval`／`wasm-unsafe-eval`仅授予公开计算线程脚本响应，为固定Emscripten发行物的embind初始化所需；正式页面的脚本策略不放宽。静态CV代码不经过业务会话刷新，不包含账户或文件凭据。

## 保存、历史与权限

不增加识别写入API，不改变数据库／Storage／RLS。草稿仍由已有正常保存路径创建／更新，固定快照、修订冲突、事件失效、幂等与测量协作保持原契约。

迟到结果用图片ID／内容哈希、草稿ID／原几何、本地编辑代数、当前选择、尚未保存及Owner可编辑状态共同校验。贴合不接受元数据输出，只替换几何，保留人工数值和来源。保存一开始即使票据失效，避免计算落在保存请求之后静默改变画布。旧保存对象不生成自动贴合票据。Guest／历史预览／只读待办不显示辅助入口，也不创建计算请求。

图片字节撤销或账号会话清理时同步取消线程并清除候选，防止保留过期私有像素。原有权限检查依然由业务API执行，客户端CV不授予任何写权限。
