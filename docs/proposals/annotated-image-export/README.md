# P2-04A 标注图片导出方案

2026-10-25。用户已明确批准「批准，按此接入现有页面」；仅本阶段图片导出，不包含 PDF、ZIP 或发布流程。

## 入口与成功路径

Owner 和有效 Guest 在现有资料图片详情的「··· 文件操作」中选择「导出标注图片」，原位展开轻量表单，不跳页、不另建工作区。归档项目仍可导出。当前阶段导出这一张图片的**当前已保存状态**；不导出编辑草稿，不新增历史时点选择器。

```text
文件名                         [···]
  下载标准图 / 下载原件（Owner）
  导出标注图片
  ─────────────────────────────
  当前已保存图片与标注（不含未保存改动）
  格式 [PNG ▼]    [生成并下载]
  生成中… [取消] / 失败说明 [重新生成]
```

PNG 默认；JPG 质量 0.92、白底。复用现有按钮、select、文字状态和分隔线；手机换行，不占用标注属性区。Tab、Enter 和触摸可操作，状态使用 aria-live，入口及操作不小于现有 40px 点击区。

## 导出信息布局

```text
项目名 / 文件名 · 当前已保存状态 · 固定时间
完整标准图（保留宽高比）
  七类已保存几何 + 图片内定位编号 + 适用数值与单位
──────────────────────────────────────────
编号 / 名称 / 修订 / 工程师人工字段
客户数值或仅照片、无法测量、待补充、待补测；来源与证据引用
文件 ID / 标准图完整 hash / 标注稳定 ID 与修订 / 相关回复 ID
绿色表示已补充；不代表尺寸齐全或技术验收。非正式 CAD 工程图。
```

保持现有几何和人工数值语义，复用七类几何绘制；没有工具栏、选择框、控制点、CV 候选或未保存输入。图中用编号和简明数值，长名称、文字备注、来源和状态在图片下方说明，避免覆盖照片。工程字段优先的显示沿用现有契约，客户数值另列来源；不将旧位置回复套到新几何上，旧回复注明所属固定修订。仅照片／无法测量不会补零或标为尺寸齐全。编号仅用于本图定位。

当前单张导出；图片区长边最多 4096px，不放大小图；标准图最多 40MP（沿用系统可用图片范围，超限提示）；含说明总画布最多 16MP、任一边最多 16384px，最多 200 个有效标注、1000 个相关未关闭测量项，说明正文最多 60000 字符。完整内容超过上限时明确提示，不静默裁掉。一次只生成一张，默认无后台任务、存储产物或新依赖。

## 一致性、权限与失败

服务端同一项目读锁内聚合已保存标准图 hash、标注 ID／修订、当前测量状态、最新回复及有权证据引用。生成只使用这次返回的固定对象；图片从原受控读取取回并核对 hash，保存前再次核权。同期间更新不混入本次内容；撤销／退出／换项目／取消时放弃结果并释放画布、图片与临时 URL。已由浏览器保存的副本不可撤回。

无标注时可导出标准图及「暂无已保存标注」；非图片没有入口。加载、网络／图片解码／画布编码失败原位提示，重试重新读取一份快照；按钮防重复提交。准备、绘制、编码及最终核权总计 120 秒上限；每批绘制让出主线程以响应取消，浏览器原生解码／编码在途不能强行中止但结束后丢弃。超限说明单张资源限制，不另加服务兜底。

## 方案选择与设计自检

推荐文件菜单原位表单、下方完整说明；不增加独立导出中心。可选仅画面无说明会失去来源／状态，不推荐。无预览弹窗和批量选择；最终 PNG／JPG 的观感及手机保存由用户少量试用。

无渐变；冷灰／白／既有蓝色操作，非暖黄主色；无 AI 装饰；仅现有菜单与一个表单，不加无意义容器层。导出图片的几何状态色沿用既有业务语义。

批准项：上述入口、当前已保存单图范围、PNG／JPG、图片下方来源说明及资源上限，用户已明确批准。微小排版按现有 UI 自主调整。
