# P2-05 ZIP资料包方案

2026-10-25。用户已明确批准「批准，按此接入现有页面」；复用现有导出与私有读取，不新增导出中心或后台服务。

## 入口与范围

Owner／有效Guest在资料区现有PDF按钮旁点击「ZIP资料包」，在已有资料条目旁勾选最多20项（图片、CAD、PDF、ZIP等均可），按需附加一个已发布交付版本中的所选附件（最多20个）。版本使用现有当前／历史分页读取；不把私有草稿或未发布附件加入资料包。也在已发布版本附件旁增加「ZIP打包附件」，原位复用同一表单。

```text
类型 [全部]  排序 [最新上传]  [PDF资料报告] [ZIP资料包]
已选资料 3 / 20 · 当前已保存状态
[✓] 正面.jpg   [✓] 零件.SLDPRT   [✓] 说明.pdf
[ ] 附带原始照片（仅工程师；默认不选）
交付附件（可选） [不附带 / V003 / V002…]
  [✓] 模型.step   [ ] 工程图.pdf
[生成ZIP并下载] [取消选择]
准备／下载 2/5… [取消] / 失败原因 [重新生成]
```

资料图片默认放去敏EXIF后的标准WebP，其他资料保持原格式；Owner勾选后额外加入原始照片，Guest没有原件选项，也不能直接请求越权。交付附件按所选已发布版本保留原有下载内容。归档项目仍可读／打包。选择沿用当前图库和加载更多；切换类型／排序清空资料选择并提示。生成中冻结选择，关闭／切项目／退出可取消。

本次包中包含选中有权文件、对应已保存的结构化标注／测量数据及其关联处理记录／固定修订引用；不包含未保存草稿、临时候选，不重跑CV。已有PNG／JPG与PDF是独立导出，本次ZIP不重复生成它们，也不声称这些浏览器临时产物已经存为交付附件。用户自行上传并发布的PNG／PDF可作为普通所选附件收入。

## 资料包组织与来源

```text
README.txt                 内容范围、格式、单位与状态含义
manifest.json              schema版本、固定时间、项目／版本引用、每文件路径／ID／大小／SHA256
data.json                  当前标准图hash、标注ID／修订／归一化几何／人工字段、测量回复／补测历史与相关固定修订
materials/<文件ID>/...     标准图或原格式资料
originals/<文件ID>/...     Owner明确选中的原始照片
deliveries/V003/<文件ID>/...  本次所选已发布附件
```

文件名保留可读部分，并以稳定ID分目录避免同名覆盖；清理路径分隔符、控制字符和危险路径片段，中文使用ZIP UTF-8文件名。manifest记录二进制文件以及data.json／README的实际大小与SHA256（清单自身不自引用）。data.json保留来源与历史固定几何，旧回复不套用后来修订；仅照片／无法测量／待补测均有明确种类，缺失值不补零。绿色不等于尺寸齐全或工程验收；不是CAD工程图或一键恢复备份。

开始时在同一项目读锁内固定所有所选身份、版本、文件hash与结构化数据；下载逐文件核权并核对真实字节hash，保存前再次核权全部所选范围。任何文件失败、失权或内容不匹配都不交付不完整包，不混入生成期间的新保存。

## 有界生成与失败

使用浏览器按需加载ZIP STORE封装（不额外压缩文件，优先减小CPU／内存成本，文件字节原样保留），没有新运行依赖或常驻Worker。最多20项资料、20个交付附件及对应Owner原图，最终最多64个条目／128MiB；结构化JSON最多8MiB、2000个有效标注、4000个当前测量项、2000条处理历史及其必要固定修订。组合超限明确提示减少选择，不截断、不自动分包或扩大资源。

串行读取、有界分块传输、共用下载内存预留与已有导出并发门控；应用缓冲估算最多512MiB（浏览器原生与GC额外），整包300秒上限。支持准备、下载、核对、打包、失败、取消／超时和重新生成状态；重试重新固定快照和下载整包，不混用上次半包。临时URL短暂保留并在退出／关闭时清理，提示交给浏览器保存，已保存副本不可撤回。

空选择且未选交付附件时按钮禁用；链接不可用／跨项目／Guest原件请求均拒绝；草稿与原版本附件有变不偷换版本。手机操作区可换行、至少40px点击区、label／键盘／状态提示沿用已有实现。
