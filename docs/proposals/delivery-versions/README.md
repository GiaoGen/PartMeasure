# P2-01 交付版本浏览方案

日期：2026-10-25。状态：用户已明确回复「批准，按此接入现有页面」。预计总计2–3小时有效工作，不含审批等待、人工试用。

## 目的与复用

保留现有工作台「资料与补测」「交付与版本」及当前交付区的位置、宽度、冷灰蓝色变量、字号、文件行和下载按钮。复用草稿上传、保存、发布、不可覆盖和受控下载，不增加页面、弹窗或第三工作区。Owner管理草稿，双方均可浏览已发布版本；Guest不显示草稿及发布动作。

## 推荐布局

```text
交付与版本（现有区域）
  最新版本 V003
  工程师发布 · 发布时间 · 2份附件
  版本说明
  文件A · 格式 / 大小           下载
  文件B · 格式 / 大小           下载

  ▸ 历史版本                 （默认收起）
    V002 · 发布时间 · 2份附件  展开
      本版本说明、附件与下载   （原位展开，不跳页）
    V001 · 发布时间 · 1份附件  展开
    上一页 / 更早版本          （每页10版）

  准备下一次成果 / 继续编辑草稿 （沿用原入口与表单）
  草稿 · 仅工程师可见
```

最新版本始终保持在上方，历史区域默认折叠；打开才读取摘要，展开某版才读取完整附件。一次展开一个历史版本，翻页不累积全部附件。草稿与已发布内容以标题和间距区分，不重复套卡片。浏览历史不卸载草稿编辑器，不丢未保存输入；发布成功后最新版本和历史同步更新。

## 关键状态与适配

- 无已发布版本：Guest显示「暂无交付」；Owner沿用上传开始交付。仅一版时历史显示「暂无更早版本」。
- 加载与失败：最新、历史列表、历史详情分别反馈，历史失败不遮住最新成果或草稿；可原位重试。
- 更新与输入：新增版本事件刷新最新并重置历史分页，保护未保存的草稿；草稿有冲突时保留原输入和现有恢复方式。
- 权限失效：复用当前会话失效处理与逐请求核权，撤销链接后不能继续读取或下载；历史接口只返回已发布版本。
- 下载：沿用现有进度、取消和重试；不新增覆盖旧版、删除历史或回滚发布操作。
- 桌面与手机均在原交付区域单列排列；版本号、日期、附件数允许换行，长文件名换行。按钮支持键盘，展开入口提供展开状态与关联区域，触摸目标至少40px。

## 数据与检查边界

新增有界历史摘要分页，按版本号倒序，并绑定项目、主体与当前最新版本上界；附件详情按需单独读，复用现有缓存及delivery事件失效。每页10版，不恢复逐字段瀑布。无schema迁移、新依赖或服务；发布与下载事务保持原契约。

必要检查：类型检查、相关lint、历史游标／读取权限及缓存失效的定向测试，少量隔离真实数据库只读验证。无浏览器／E2E或部署；最终阅读、折叠展开、手机触摸手感交人工。

## 设计规范自检与批准范围

纯色沿用现有变量，无渐变；主色沿用冷灰蓝，无暖黄主色；无AI装饰、发光或新动画；使用标题、文件行、间距与分隔线组织内容，无多层无意义容器。

本次需批准：在现有交付区按上述方式增加「最新版本」身份、默认收起的「历史版本」、原位详情和每页10版翻页。其余发布／草稿／下载流程复用既有实现。
