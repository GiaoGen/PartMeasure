## 已修正的生产代码

| 位置 | 缺口及处理 | 用户影响 |
|---|---|---|
| `http.ts` / `bounded-stream.ts` | JSON请求保留64KiB实际字节上限，提前拒绝超限Content-Length，精确判断JSON MIME；增加15秒读取时限及取消。不等待不配合的流无限结束 | 慢请求或伪造声明不能长期占用处理；正常表单契约不变 |
| `auth-fetch.ts` / `auth.ts` / `proxy.ts` | 真实Auth单次HTTP请求上限15秒，保留调用方取消。官方SDK自身可能有有界重试，因此不把15秒称为整次认证总耗时；继续真实认证，不引入离线成功或托管内存限流降级 | 认证服务故障时等待有界，既有本地登录修复保留 |
| `file-response.ts` / `transfer-budget.ts` | 受控下载/预览每实例最多24个在途、同一Owner/Guest最多8个，保留数据库共享频率限制；60秒整体传输租约覆盖慢消费/不消费，结束、取消、失败、超时均释放；核对元数据字节数、实际字节数及206范围，限制上游异常响应 | 避免多次下载无界占用服务端资源；排满时显示可重试提示，文件与导出功能保留 |
| `file-authorizer.ts` / 文件路由 | 初次核权后，在Storage/共享缩略图等待结束、返回正文前再次核权；长流每5秒或累计8MiB后的下一次输出前核对项目/链接/文件，Owner同时按需刷新真实身份。缩略图命中、Range、当前/历史交付附件均走同一受控通道 | 撤销或隐藏在等待期间提交后，不把旧等待结果继续当作有权；长下载遇失权停止后续输出 |
| `upload-grant.ts` / 上传路由 | 发上传凭证前检查原上传主体、可写项目、15分钟窗口；Storage已有对象也必须重新核对可写权限；签名后再次核对撤销/归档/状态并记录期限，未知Storage错误不当成对象缺失 | 归档/撤销发生在网络等待期间时，不返回迟到的上传凭证或成功状态 |
| `complete-upload.ts` | 源文件落盘校验管线显式接入既有45秒处理deadline/请求取消，仍验证实际大小、hash、格式、40MP图片及预留派生预算，最终提交继续重新核权及检查处理令牌 | 取消/超时更早停止落盘；不放宽文件与配额政策，仍为format-only-v2 |
| `upload-cleanup.ts` / `scripts/p3-03/cleanup-uploads.ts` | 新增一次性、默认dry-run的受控清理；每批最多20项，120秒工作信号、5分钟租约，失败保持配额，最多5次后保留待人工处理。按项目/预留生成固定对象键，拒绝任意存储路径；逐个确切对象404确认后才释放预留。ready记录仅删除隔离重复副本，保留私有文件 | 取消/拒绝/失权留下的孤儿对象有安全回收代码，历史及已发布文件不被当作垃圾删除 |

清理只在上传凭证、请求处理及旧任务租约均过期后进行，并留2分钟余量；先锁账户额度→项目→预留，领取令牌后离开SQL事务再操作Storage，结算时复核令牌/租约/状态/引用。旧处理无法凭过期令牌提交。任何对象删除失败、权限未知、仍存在、处理权变化或配额结算失败，都不释放额度。

没有给生产环境配置定时任务，也没有在云端执行删除。清理CLI当前硬限制原隔离项目、受限worker连接和非生产环境；它只是短时维护工具，不能直接当作生产运行方案。P3-04仍需安排真实维护执行/调度与操作记录。遗留缩略图任务、事件/限流等运行数据的保留维护继续纳入P3-04，不借本轮删历史或任意清空幂等记录。

| 范围 | 服务端边界及本轮证据 |
|---|---|

| 分享/既有会话 | 每次业务读取/写入检查会话→链接的项目、到期及撤销，读写锁与撤销串行；恢复不复活已撤销分享。新签名返回和下载等待路径补二次核权 |
| 上传/资料/原件 | 预留按账户/项目/当日预算及2个主体/4个项目在途限制，实际文件大小/hash/格式独立校验，Guest不能上传交付用途或取Owner原件；服务端路径不采用客户端任意输入 |
| 七类标注/CV/测量 | Owner写，图像hash/规范坐标/固定修订及冲突保护保持；CV只生成本地候选，不改变服务端身份或人工数值权限。Guest只读当前可见标注及既有测量快照，不能列Owner私有修订；回复身份/证据归属及100轮上限、审核权限保留 |
| 私有交付/历史版本 | 草稿及内部文件对Guest不可见；发布校验1–20附件和单调版本，事务/数据库触发器冻结发布内容及附件引用；历史受保护文件不能静默隐藏。下载仍按具体交付附件集合及文件两次核对 |
| 反馈/接收 | 仅有效Guest在已发布版本追加，Owner只读；撤销仅本次会话当前接收记录，旧留言/接收保留，1000条版本上限。归档后禁止追加 |
| 归档/恢复 | 双方可读、写入由DAL及数据库触发器拒绝；Owner可恢复/撤销；不删除文件、不改固定历史、不复活撤销链接 |
| PNG/JPG/PDF/ZIP | 保留已批准选择数/字节/页数/正文/时间上限；源数据是有权限的固定快照，图片/附件走受控读取，生成后保存前再读`image-access`或`zip-access`核对。Guest原件与私有修订拒绝，不能用UI禁用替代后端核权 |
| 内存/IndexedDB/事件 | 持久图片只存有界字节及逐出元数据，复用前仍请求新鲜访问清单；退出/换账号、失权事件清理。SSE继续最多24连接/4分钟租约、队列背压、事件读取核权，缓存与事件游标不作为授权凭证 |
| 日志/错误 | 继续固定错误码、请求ID及脱敏依赖诊断，不返回数据库异常原文、Cookie/OTP/密码/签名URL；维护与验证脚本只输出计数/阶段/有限错误码，凭据不写报告 |
