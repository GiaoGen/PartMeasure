# 项目说明、分享与图片悬停细节 · 2026-10-21

用户本轮直接授权三项细节调整；未扩展业务流程、数据库结构或部署。

- 「编辑说明与分享」展开时提供 180ms 高度展开和淡入，遵守系统减少动态效果及已有动效设置。
- 新生成的分享地址保存在当前浏览器的有界本地记录中（最多 32 份），刷新／返回项目后根据服务端当前分享 ID、有效期、撤销状态恢复；仅工程师页面读取，Guest 不展示。轮换不误显示旧地址，撤销／过期移除，登录／退出／认证失效及跨页签身份通知时清理；普通页面退出只清内存，不误删该本地副本。禁用本地存储时本页仍能复制新地址，并提示刷新不保留。
- 数据库仍只存分享令牌哈希，没有将链接或令牌写入数据库、日志、代码或报告。浏览器副本包含完整持链访问地址，沿用本机登录会话范围；不是可绕过权限的缓存。恢复必须先拿到正常 Owner 项目数据。清除网站数据、换浏览器／设备或重新登录后不保证能恢复；此前已丢失的旧链接不能从哈希反推，需要显式重新生成一次，不能自动替用户撤销。
- 待办面板标准图不再显示缩小／放大／适应图片三个按钮；工程师照片编辑器工具栏保持原样，画布现有手势／滚轮行为继续可用。
- 缩略图变白根因：透明 `.thumbnail-browse` 全图按钮的旧 hover 规则优先级低于 `.workspace-redesign button:hover:not(:disabled)`，被填上背景而遮住图片；标注命中按钮也有同类风险。现已显式覆盖悬停／按下／键盘焦点时的背景，移除命中区圆角块和按下时清空定位变换的样式。命中区始终透明，标注本身悬停／聚焦时提亮，线宽不变，不绘制粗大选框。

检查：lint、类型检查、生产构建、33 个测试文件／201 项测试 PASS；新增分享恢复、项目／链接 ID 隔离、轮换竞态、撤销过期、URL 限制、刷新与登录清理差异、存储边界及禁用存储覆盖。

未启动浏览器／E2E、未部署；展开和悬停的视觉、真实手机触摸仍待人工确认。人工可快速检查：展开设置→生成新链接→刷新后地址仍可复制→撤销后消失；缩略图空白区域悬停照片不变白，标注处仅标注提亮；待办图片上方无三个工具按钮，正式编辑器仍有工具栏。
