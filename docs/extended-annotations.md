# 手动标注工具扩展 · 实施与验收

2026-10-20。用户批准基于现有代码实施 CAD 式线段端标、角度、圆弧、椭圆；并进一步明确椭圆主要标记斜拍正圆，默认实测孔径 Ø，可选长半轴 a。本次不实施 OpenCV、不部署生产，不扩展其他 P1/P2。授权同步至 AGENTS.md。

## 已实现

- 线段：两端垂直短端标、小箭头、居中尺寸标签；短线箭头移外。装饰尺寸随屏幕缩放补偿，无长尺寸界线。Konva 与缩略图共用几何呈现。
- 角度：第一端点→顶点→第二端点三次点击；支持反角、三点编辑和显示弧半径调整。角度数值由人填，固定 °，不以照片夹角自动填值。
- 圆弧：连续点击起点→经过点→终点，不需要拖动。保留经过点所指定的大/小弧；拒绝重合、近共线和超出图片的弧。默认补半径，可选择弧长、圆心角或多个独立字段；不自动互算真实数值。
- 椭圆：拖动两端确定一条完整轴的方向与长度，松开后调整垂直轴、中心移动、两轴控制与旋转手柄，轮廓仅定位。默认补人工直径 Ø；选填切换至长半轴 a。无需两轴实测，无槽孔工具，不从轴比推算圆孔尺寸。切换尺寸含义后按当前字段生成待补，旧回复保留。
- 沿用自动待补：缺要求尺寸保存后生成对应项，客户在「标注与属性」数值/照片/无法测量三选一，工程师原位确认或退回。Guest 无编辑几何/审核权限。
- 沿用保存中/成功/失败重试、单会话撤销重做、修订历史和乐观并发冲突；新位置保留旧快照并结束旧待补，角度弧显示半径变化不重建待补。
- 工具栏常驻选择/线段/圆孔/角度，其余进入“更多”；零半径预览不生成非法弧路径；三点工具提示当前步骤，取消/Esc 丢弃未完成形状。未新增主 Section、识别按钮、服务、常驻进程或运行依赖。

## 数据及安全

旧四类 schema_version=1；angle/arc/ellipse 为 2。所有控制点继续采用 EXIF 标准图的原图归一化坐标；圆的像素等半径规则不变。椭圆垂直轴、旋转边界和圆弧拟合在标准图像素空间计算，再存归一化点。坐标、缩放、DPR 皆不生成实物尺寸。

新增 metadata：angleValue、arcLength、ellipseMeasure（diameter 默认/majorRadius）、majorRadius、arcQuantities。dimension 沿用长度/圆孔径/圆弧半径，按几何类型解释；deg 仅角度字段合法，长度仍 mm/cm/m/in。孔径和长半轴分别为独立人工值，切换选项不会擅自除二或乘二；相同标注已有长度字段变更单位时只作单位换算，角度独立。

正式迁移：supabase/migrations/20261020085909_extended_annotation_tools.sql。仅扩展当前几何/版本/测量字段及单位约束和原有触发器，不增表，不重写旧数据/历史，不修改 Auth/Storage，不加入本机替身。函数 security invoker、空 search_path，授权仅受限 runtime，RLS 和逐请求授权沿用。禁止在已有标注 ID 上变换几何类型；应新建对象以保留类型/历史身份。

迁移已应用到 rvysclscetfqicpnzlra（partmeasure-p0-0-lab），项目状态 ACTIVE_HEALTHY；证据 docs/evidence/extended-annotations/migration.json 含迁移 SHA256。未部署 Vercel 或生产，远端网页须另行更新构建才会显示新工具。
