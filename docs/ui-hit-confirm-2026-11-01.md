# 确认弹窗居中与标注描边选择

2026-11-01（Asia/Taipei）。用户审查方案后批准开始修改。本批本地实现和验证完成，未提交、推送或部署；保留前面的登录入口和箭头文字全部未提交成果。

## 修改结果

共用确认弹窗显式按 visualViewport 的宽、高及左右／顶部偏移居中；无该接口时回退当前窗口。监听可见视口 resize／scroll 及窗口 resize，使用一帧一次的更新；关闭时清理监听和帧回调。样式保留屏幕边距、内部长内容滚动、原有浅／深色、遮罩、焦点约束及进出场。居中使用独立的 CSS translate，动效继续使用 transform，避免相互覆盖。未保存切换、归档、交付放弃／发布及接收记录撤销均复用此组件。

编辑器和图库共用新的前端描边选择器，使用既有可见几何生成的 Path2D 与浏览器原生 isPointInStroke，圆、圆弧、角度、椭圆的内部及外框不再参与选择。鼠标容差为屏幕 5px，触摸为 10px；换算缩放后保持屏幕容差一致。候选按到描边的距离选择，数值精度内相同的候选沿用最后绘制顺序。旧点位保留真实填充区域，尺寸文字和箭头正文保留文字块选择；编号、白色辅助描边及选中时的辅助轴不扩展实际选择区。

编辑画布关闭空心路径的填充命中；在同一入口选择最近标注并跟踪整图形拖动，避免 Konva 先命中靠上的图形后拖错对象。保留先选中再拖动的操作、3px 拖动阈值、图像边界限制、最新草稿冲突检查，以及只读、取消、切图、失焦、多指和撤销逻辑。整图形预览按 requestAnimationFrame 合并，指针移出画布后仍能正确结算或取消。

图库的原矩形按钮只保留键盘焦点和 Enter／Space 操作，pointer-events:none；指针从照片入口按真实路径选标注，空白点击继续浏览照片。横竖图按 contain 的实际留白、尺寸换算，不拉伸坐标。悬停判定也合并为一帧一次。

这次没有修改 API、后端、权限、数据库、依赖或环境配置。此前箭头文字新增的生产校验迁移仍未应用；本批前端修复不代表此前整批变更已经上线。
