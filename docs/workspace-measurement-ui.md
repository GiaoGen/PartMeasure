## 已实现

- 工程师与客户页共用新布局，主要区域命名为「资料与测量」。桌面浏览资料时保留约 3:1 的资料/交付双栏；进入照片后右侧改为「标注与属性」，客户为「测量提醒与回复」。进入具体提醒时右侧显示回复或审核及历史，退出恢复交付区。
- 右侧通过 React portal 显示同一编辑器拥有的属性与表单，不另开一份标注会话。交付组件继续挂载，切换上下文不清空交付草稿。手机继续单列展示资料；照片下方显示属性/回复，不挤成窄双栏。
- 资料图以已有受控标准图为底图，按标准图宽高和归一化几何叠加已保存标注；没有重新上传或覆盖原图。可视区域附近才读取标注，SVG 预览不实例化 Konva 编辑器。保存后只刷新对应照片的预览，不因选择文件而批量重读全部标注。加载失败可点击照片重新读取。
- 工程师画布只常驻线段、圆/孔位、点位、文字四种绘制按钮。一次绘制后回到直接选取；标注可选取、拖动及调整线端/圆半径。空白拖动、空格/鼠标辅助键平移、滚轮和双指缩放、双击空白复位沿用真实画布坐标变换。删除、撤销/重做及修订入口移至属性上下文，键盘操作保留。移除缩放比例、放大/缩小、适应视口、原始像素的常驻控件。
- 属性按几何类型显示，孔深、孔类型、螺纹等收进可展开的「孔位属性」。测量提醒名称复用标注名称，避免重复填写。普通文字标注可以只保存，不必创建测量提醒。
- 「发送测量提醒」先校验要求，再复用已有标注保存流程，取得成功返回的真实修订，最后调用原有测量请求创建接口。保存失败、标注已删除或返回了其他标注时停止，不提交错误引用。输入、幂等重试、修订冲突和离开保护继续保留。单独「保存标注」仍可用。
- 客户不能绘制、编辑标注或发布提醒；继续使用数值、照片、无法测量三种回复，工程师可确认、人工录入来源或要求重新测量。文件问题继续可创建、回复和处理；回复/审核历史保留，待审核时默认展开。
- 折叠的任务汇总每 20 秒在页面可见时刷新；展开后不自动重排，仍可手动刷新。这里的「发送」表示创建客户可读取的站内测量提醒，不发送邮件、短信或外部消息。
- 下载、原件下载及隐藏收进文件操作菜单。文件编辑时隐藏新增资料的悬浮按钮，保留已启动上传队列。空状态精简为「暂无资料」「暂无交付」等。
- 页面切换渐隐后进入新内容；折叠项、菜单与表单使用短过渡，菜单退场只渐隐。表面使用低饱和度实色、大圆角；尊重减少动态效果偏好。未新增动画库。

## 后端待办：仅记录，未实施

### 私有标注草稿与显式发布

现有保存接口会使标注按原有权限可读，保存不是私有草稿。不能仅靠前端隐藏声称客户看不到。若需要「编辑过程中保存但客户不可见，点发送才公开」，后端须明确草稿/发布状态、发布修订与可见性，并在 Owner/Guest 读取、RLS 和受控预览上执行。发布后编辑是否继续展示旧修订也需定义。此处不能直接复用交付私有草稿的权限假定。

### 多标注与提醒的批量原子发布

当前为原有单条接口的顺序调用。保存整个当前照片会话可能包含多个标注，某一保存或后续提醒创建失败时，之前成功保存的标注不会回滚；UI 保留失败状态和重试，不声称整批原子提交。若要一个上传动作同时公开多个标注并各自生成提醒，需服务端批量事务、整批幂等键、逐项修订校验、失败恢复和返回结果契约，不能前端用 Promise.all 模拟事务。

### 持久标注编号与查询关联

当前照片上的编号是当前可见标注列表的显示顺序，不是数据库永久编号；隐藏标注后可能重排。历史测量位置依照既有固定修订和名称识别，不额外画一个误导性的「1」。若要求编号在隐藏、跨设备及历史请求中永远不变，需后端分配不可复用的文件内编号并将其纳入测量位置快照。文件提醒列表摘要目前没有 annotationRef，精准按选中标注筛出全部已发提醒需扩展摘要/查询契约；当前显示该文件的提醒，打开后查看冻结的位置，不能凭名称猜关联。

### 大批量照片预览

当前复用单文件标注读取与标准图私有预览。更小派生图、带修订摘要的批量标注预览，以及跨设备更新的版本标识可减少大量照片时的请求和图片内存；需另行定义受限查询、派生规格与缓存失效，不能开放公共图片或绕过会话。当前未新增这些后端能力。
