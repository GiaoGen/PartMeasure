## 本轮修正

| 位置与问题 | 代码处理 | 用户层面的变化 |
|---|---|---|
| 取消浏览器返回可能重写前进分支 | 支持Navigation API时在历史提交前取消；无法提前取消但能读取entry位置时按实际偏移恢复。旧浏览器的已知工作台历史仍按计数恢复；移除监听时不干扰后续页面 | 在支持的浏览器路径下，取消离开保留原位置和前进历史；一次允许的返回只询问一次 |
| 只换Tab仍重复提示，返回可能重设同一个编辑会话 | 比较实际文件/标注/事项/筛选上下文；同上下文只换Tab保留挂载与输入，真正换对象/离开仍保护。工作台外目标不按Tab误判 | 资料和交付间切换更直接，草稿与传输继续保留 |
| URL回到无标注时仍选着旧标注，或定位新资料期间显示旧照片 | 显式外部选择清空可取消当前标注；定位其他未加载目标时先撤下旧对象，避免URL和画面指向不同资料 | 返回与当前选择一致，加载时不把上一张图误当作新目标 |
| 文件定位缺元数据 | 当前工作台内保留最近20份实际打开资料的定位信息，文件/重同步事件及失权时清除，不持久存储或缓存授权；复用已加载对象和现有受控读取 | 同次会话跨分页/筛选返回已开资料时，尽量保留真实文件名并支持附件定位；没有全量扫描 |
| 确认后组件已关闭，旧回调仍可能继续；保存结果可能跳回旧对象 | 确认与UI写入绑定组件/视图生命周期，提交期间卸载或上下文变化使旧回调失效；写重试仍绑定原URL/方法与原幂等键。隐藏A文件后的迟到结果不清空随后打开的B文件 | 关闭/返回/切换后，旧操作不会再把当前界面带回旧对象；不把旧输入提交到新对象 |
| 上传处理完成或重同步迟到后通知已离开的页面 | 完成读取后再次核对原取消信号，过期队列不发送ready回调；保留原上传处理与恢复机制 | 旧上传完成不会刷新错误页面或干扰后来的工作区 |
| 多层弹框独立改body overflow，先关底层可能解锁或锁死页面；快速重开被旧退出回调关闭 | 共用有计数、可重复安全释放的滚动锁；原生close和卸载释放资源，重新打开取消旧关闭定时器，忽略已重开的弹框收到的旧close事件 | 弹框叠加和快速开关时，背景与滚动状态更稳定 |
| 手机软键盘缩小视口后，输入可能落在弹框边缘 | 复用现有visualViewport/焦点事件的合帧处理，仅必要时滚动弹框内部当前输入，不移动背后图库 | 为软键盘出现后的填写/提交保留可见空间；具体设备手感仍待验 |
| 交付区固定等待500ms；隐藏区仍读取清单；离屏缩略图持续持有图片 | 移除交付读取前500ms定时等待；隐藏资料/草稿文件区停止或合并到下次可见时读取，上传与写入会话不卸载；文件栏离屏释放图片租约，父回调变化不重新读取图片 | 少一段固定等待，切到交付时减少无关图库工作，浏览长文件栏时资源持有更有界 |

已发出的写请求仍可能在服务端完成；本次屏蔽的是过期UI副作用，不冒称“关闭就撤销服务端事务”。保存、幂等、修订、固定历史和核权接口不变。

## 设计、动效与边界

- 沿用定稿布局、浅色/深色/跟随系统、七类icon、待办模态框与原横滑/下方详情、手机图库点标注原位弹框及全部下载/导出/反馈能力；没有新增业务页面或修改几何/CV算法。
- 入场160ms/退出120ms、小幅位移和opacity沿用原规则。退出期间保留模态约束，快开重开会取消过期关闭回调；减少动态效果继续取消动画等待。没有新动画库、重模糊、巨大阴影或逐帧尺寸动画。
- 新增视图所有权与滚动锁是当前组件的生命周期管理；文件定位信息仅当前工作台内最多20项，不是新的网络缓存、离线权限或持久草稿系统。现有缓存、图片预算、上传流水线及下载/导出资源上限继续复用。
- 本轮没有修改后端/API/认证/RLS/Storage、migration、依赖/lockfile、网络或部署；保留已有登录修复与未提交成果。
