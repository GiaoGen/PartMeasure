# 标注即协作对象：实施与验证

2026-10-21 用户新授权已取消工程师确认步骤：客户提交即绿色，仅工程师要求补测时黄色，编辑器显示编号。当前行为及验证见 [客户提交即完成](annotation-completion.md)。下文确认流程保留作历史记录，不再是当前交互要求。

2026-10-20。批准依据：用户审阅了“工程师标位置 → 缺失自动提示 → 客户原位补充 → 工程师原位确认”的流程后，明确回复「可以的开始按这个改」。这项授权替代旧交互中的“发送测量提醒 / 查看关联提醒 / 另发提醒”，其他权限和历史约束继续适用。

## 实际行为

- 双方点击标注都打开「标注与属性」。工程师保存线段、圆孔时，缺尺寸自动生成待补项，不需要发布。操作说明和测量方式收进属性，说明可留空，使用明确的默认提示。
- 点位和文字默认只作说明；点位可明确要求尺寸；线段/圆孔也可设为“仅说明”。圆孔可勾选要求孔深，直径/半径与孔深分开补充，不把选填螺纹、备注都算缺失。
- 客户直接看到数值、照片、无法测量三种回复方式；提交后等待工程师确认。工程师直接查看最新证据，确认、人工录入或要求重测。无法测量也需要工程师处理，不自动完成。
- 确认值由同一事务写回标注相应人工字段并追加标注修订；原回复、证据、审核来源及位置快照不变。孔径和孔深共用单位，确认采用不同单位时换算另一项已知人工长度，限制到六位小数；过小/超范围则拒绝整次确认，避免静默换单位或部分提交。这是长度单位换算，不是像素推算尺寸。
- 工程师直接填写尺寸、设为仅说明、取消孔深要求或隐藏标注，会结束对应未完成事项，记录操作者、原因和当时的标注修订；不伪造客户回复或审核。历史默认折叠。
- 修改几何位置、直径/半径含义或测量要求时，旧未完成事项结束并保留快照，新的缺失项引用新修订。旧页面向已结束事项回复/审核会收到 409，不会把旧答案套到新位置。
- 重复保存不创建重复待补；幂等提交复用既有结果，其他并发提交检查修订。标注按项目锁后执行与事项的写入，保持原事务适配器及 RLS。文件问题仍独立于标注。
- 已有测量事项继续读取，未重建/删除旧回复。兼容旧 POST measurement 接口供历史客户端使用，正式 UI 已移除显式发布入口；旧客户端不应与新 UI 混用作验收。

## UI、同步与缓存

属性面板直接挂载现有回复/审核组件，不额外跳转。待办汇总继续保留；能找到对应资料时，点击直接定位标注。资料未在当前分页中时复用既有快照详情，避免错误定位。大图显示待补充/待确认状态，缩略图编号旁小点表示该处有未完成项。

继续复用项目事件流，不加轮询频率、转发层、公开桶或常驻 Worker。仅当前选中标注读取关联项，历史展开时才挂载历史详情/画布。事件失效相应文件标注和事项缓存；保存标注与确认也失效相应缓存。远程更新保留选中标注；标注草稿/客户未提交输入不会被自动读取覆盖，提交时仍检查服务端冲突。未做大陆手机速度或即时送达 SLA 宣称。

使用正常登录，凭据继续从 ignored 的 `tmp/p0-1/test-passwords.txt` 查看，不添加认证后门。最新独立测试项目入口和客户链接保存至 ignored 的 `tmp/annotation-collaboration/manual-entry.txt`；不把客户链接贴进报告或截图。
