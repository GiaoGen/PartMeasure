# 双端补充区：当前状态优先 · 2026-10-21

批准依据：用户审阅双端补充区示例后回复「可以，并且历史记录里，工程师和客户可以用颜色进行区分」。本轮实施该方案及角色配色，不改业务状态机、权限、数据库或部署。

## 已完成

- 工程师端优先查看最新回复与要求补测入口；客户端优先看到工程师要求、填写／照片／无法测量入口。两端使用统一的字段名和状态。
- 待补测时首先显示工程师原因，旧值仅作为「上次提交」的小字，不再占据主结果位置。工程师端提示等待重新提交，客户端直接填写新信息。
- 提交后主要展示最新数值、照片或无法测量说明；不重新引入工程师确认步骤。历史人工确认值仍按原记录来源显示，原客户回复不覆盖。
- 历史默认折叠，按时间显示「谁／做了什么／时间」，默认不显示秒。工程师蓝色、客户绿色，同时保留文字角色；角色取自记录的实际 authorType，客户自填称呼不能改变配色身份。
- 历史及证据按需展开，证据照片不在折叠状态加载。不新增查询、轮询、第三方依赖或服务。
- 日常补充区移除重复照片、缩放工具及「测哪里」通用说明；明确配置的方法、测量说明按需显示。历史中的「查看当时位置」在工程师主画布展示既有固定快照，保持只读，并可返回当前标注；未保存输入时先提示处理草稿。
- 多字段圆弧、孔深等仍按字段分别显示和补测，所有回复、附件、工程师理由、旧来源和修订继续保留。文件级问题历史仍按文字问题描述，不改为数值任务。

## 人工复核（约 3 分钟）

1. 工程师选择一项待补测标注：原因在前，旧值显示「上次提交」，日常区域无第二个画布；不出现重复旧属性。
2. 客户打开同一标注：可看到原因并重新填写。仅传照片／无法测量时不保留禁用的数值框；成功后仍按原流程变绿。
3. 双方展开历史：工程师蓝、客户绿，并有角色文字；旧值、原因、附件仍可查看。折叠后主体保持简短。
4. 工程师从历史点击「查看当时位置」：主画布显示保留的原修订，编辑禁止，返回当前标注后恢复；存在未保存输入时提示先保存。
5. 检查角度、圆弧多字段、孔深：客户端输入标题与单位对应当前字段，记录不串项；窄屏历史文字能换行。
