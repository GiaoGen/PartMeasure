## 角色、入口与显示边界

- 工程师在现有“测量要求与备注”中选定方式后，在方式字段下查看对应帮助；不挤占或重复照片画布。
- 客户在现有测量回复／待办填写区的方式行下查看，先了解固定标注位置和补测原因，再按需阅读帮助。帮助只改变本地展开状态，不保存任何业务数据。
- 复用一个帮助组件和同一份静态内容，覆盖编辑器、待办与客户手机弹窗；客户弹窗的兜底方法说明仅在没有当前补充区时显示，避免同一区域重复入口。
- 仅 `outside / inside / depth` 提供教程；未指定／其他／文件文字问题不显示卡尺教程。角度数值不显示长度卡尺教程，仍按工程师说明测量；不从几何类型猜测方法。
- 回复使用请求固定的 `measurementMethod`，不拿后来修改的标注方法替换历史任务；孔深继续采用其任务实际的深度杆方法。

## 交互与关键状态

| 状态 | 处理 |
| --- | --- |
| 默认／方法未指定 | 默认收起；无适用方法则不占位，不要求用户先选工具才能回复 |
| 展开／收起 | 使用原生 `details/summary`；只展开帮助正文，不重建表单、清空输入或触发详情请求 |
| 方法／任务切换 | 帮助按方法与任务身份更新并回到收起；沿用当前未提交输入提醒 |
| 帮助图片未加载／失败 | 步骤文字独立完整；本地图片按需载入，可重新展开重试，不阻断填写或提交 |
| 仅照片／无法测量 | 保留原回复路径；教程末尾明确可用这两种方式，不新增确认 |
| 已提交／历史 | 当前回复维持现有展示；历史不额外铺开教程，不改原快照、状态或工程字段 |
| 权限／撤销 | 继续由原页面处理；帮助无请求、无凭据、无业务写操作，不授予任何权限 |

桌面和手机都原位单列展开；图像宽度随现有面板收缩，不产生横向页面滚动。`summary` 提供至少 44px 的触摸区域、键盘 Tab/Enter/Space 与明显焦点；图像有中文替代文字，步骤不依赖图中文字或颜色。手机软键盘／滚动手感最后人工确认，自动检查仅核对内容选择、默认折叠和回复路径回归。

## 图文内容与实现边界

三种接触方式和两种读数方式使用五幅自绘 SVG，无外部图床、视频或新依赖；不复制厂商插图。读数图明确分度值、单位与示例公式。工程师指定的位置、基准与要求优先；不推算真实孔径、角度或尺寸完整性，不建设教程后台、课程／进度或 AI 教练。

内容依据：Mitutoyo 官方 [卡尺使用说明](https://www.mitutoyo.co.jp/about-metrology/knowledge/calipers/)、[读数说明](https://www2.mitutoyo.co.jp/eng/useful/E11003/pageindices/index20.html)、[内测／深度及视差说明](https://www2.mitutoyo.co.jp/eng/useful/E11003/pageindices/index23.html)。中文短文为项目自行编写，图为项目自绘；帮助不是具体仪器说明书或校准证明。

## 设计规范自检与备选

沿用现有冷灰文字、白底、蓝色重点和分隔线，**无渐变、非暖黄主色、无 AI 风、无装饰套卡**。帮助区域只以留白和必要分隔线组织，嵌套折叠分别承担“是否需要帮助”和“使用哪种读数工具”的实际用途。

备选是弹窗或独立帮助页，可容纳长内容，但会打断当前填写并引入新的导航与关闭状态。本阶段推荐原位轻量折叠。待批准的只有上述完整入口与展开方式，无需逐个小按钮再审。

按已批准入口接入共用组件，做定向 lint／typecheck／相关单测及一次构建，提供 3–5 分钟人工阅读／手机清单。无浏览器/E2E、数据库迁移、生产部署或远程 Preview 更新。独立示例保留审阅时的“待审”说明，作为当时的提案记录；批准状态以本节及交付报告为准。
