# 实时协作与图片快速路径：集中人工检查

状态：待人工验证。约 5～10 分钟；本轮依据工作约束未启动浏览器/E2E，没有新 UI 截图或真实手机结果。此清单不要求重做完整 P0 验收。

先选稳定的测试环境；当前部署状态与入口见 [实施报告](performance-s34.md)。工程师使用原有正常密码登录；Guest 使用该工程师新建专用测试项目的正常分享入口。不要在聊天/截图中展示密码、分享能力链接或签名地址。旧测试数据保留，不撤销已有业务项目链接。

| 步骤 | 预期结果 |
|---|---|
| 桌面工程师与手机 Guest 打开同一专用测试项目，保持在线 | 两端更新状态可见；正常操作无需“刷新任务/刷新交付”或刷新页面。记录实际等待，不只看“已连接”。 |
| Guest 上传 1～5MiB 正常手机照片 | 立即有本地操作反馈/进度；对方自动看到处理状态，扫描完成后出现小预览；未 ready 不可下载。Worker 未托管/未启动时应如实停在处理中，不假装完成。 |
| 工程师在既有图片上保存标注、发测量请求；客户填写三种回复之一；工程师确认/重测 | 另一端对应列表与详情自动更新。位置和来源准确，未改变像素到真实尺寸的约束；不能靠轮询15～30秒才能看到。 |
| 客户回复文本输入一半时，工程师修改其他内容；交付说明/标注也各试一次 | 远端更新不清空本地草稿、不闪烁卸载表单；同一实体发生并发更改时提示保留输入并在提交时拒绝旧修订。 |
| 工程师准备/发布多附件交付 | 私有草稿不向 Guest 泄露；发布后客户自动看到并能下载；失败可重试。 |
| 手机切后台再恢复；短暂断网后重新联网 | 自动重连，状态追平，无重复条目；在线恢复后停止故障补偿请求。没有重复弹窗或每秒全量重读。 |
| 工程师撤销本次专用测试链接 | Guest 旧连接与后续请求拒绝，缓存清理，不继续取得新事件或私有图片；已下载副本无法收回。 |
| 列表多图、打开标准图再关闭重开 | 列表只传小图；标准图清晰、方向正确、标注位置不变；重复打开能复用当前标签页内存缓存，退出后清理。手机触摸与输入不卡顿。 |

大陆实测须在真实大陆移动数据下完成登录、分享、照片上传、回复、私有下载和实时连接，记录运营商、设备/浏览器、粗粒度地区、是否代理以及每步耗时/错误。Wi-Fi、桌面 viewport、数据库可访问或开发机清空进程代理变量均不能代替。性能目标见 [原方案第 7 节](realtime-performance-plan.md#7-大陆直连诊断与性能门槛)，尚未宣称达成。
